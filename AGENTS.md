# Правила роботи над «Камінь Коростишів»

1. Мова інтерфейсу й документації для власника — українська.
2. Не змінювати візуальну систему без конкретної причини: шрифти, кольори,
   відступи й композицію перевіряти окремо на телефоні та комп’ютері.
3. `v0.1.0` — незмінна базова версія. Нові зміни виконувати в окремій гілці.
4. Не зливати Pull Request у `main` без прямої команди власника.
5. Контактні та брендові дані зберігати централізовано в `app/site-config.ts`.
6. Дані каталогу не дублювати в JSX; використовувати `app/data/catalog.ts`.
7. Не показувати користувачу фальшиве підтвердження надсилання заявки.
8. Заявка в майбутньому має спочатку надійно зберігатися в D1, а сповіщення
   Telegram — створюватися в outbox у тій самій транзакції.
9. Закупівельні ціни, націнки, секрети й приватні файли ніколи не передавати
   до публічного JavaScript і не зберігати в репозиторії.
10. Для анімацій завжди поважати `prefers-reduced-motion`; контент має бути
    доступним і без JavaScript.
11. Після зміни UI виконати lint, typecheck, test/build і візуальну перевірку
    щонайменше у вузькому та широкому viewport.
12. Оновлювати `docs/PROJECT_STATUS_UA.md` і відповідний розділ архітектури,
    якщо змінюється поведінка, структура або інфраструктура.

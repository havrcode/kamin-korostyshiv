# Бренд Kaminchyk і файли емблем

Оновлено: 1 вересня 2026 року.

## Прийняте рішення

Основний бренд сайту — `Kaminchyk`. Активна емблема — мінімалістична K у
заокругленій кам’яній формі з невеликим бронзовим акцентом. Саме вона
використовується у шапці, футері, favicon і Open Graph.

Варіант Angel не видалено: він збережений як резервний напрямок для можливого
майбутнього експерименту, але зараз ніде в UI не показується.

Канонічним джерелом є останній архів, назва якого закінчується на `corrected`.
Файли в `public/brand/kaminchyk` побайтово звірені з ним. Контрольні SHA-256
записані у `public/brand/kaminchyk/CHECKSUMS.sha256`.

## Структура

```text
public/brand/
  kaminchyk/
    k/                       активний напрямок K
      Kaminchyk-K-full-dark.png
      Kaminchyk-K-full-light.png
      Kaminchyk-K-emblem-dark.png
      Kaminchyk-K-emblem-light.png
      Kaminchyk-K-name-dark.png
      Kaminchyk-K-name-light.png
    angel/                   резервний напрямок Angel
      Kaminchyk-Angel-*.png
    CHECKSUMS.sha256
  archive/
    old-kamin-korostyshiv-mark.svg
    favicon-before-kaminchyk.svg
public/og.png                попередній Open Graph, збережений для історії
public/og-kaminchyk.jpg      активний соціальний preview
```

`full` — емблема разом із назвою, `emblem` — тільки знак, `name` — тільки
напис. `dark` призначений для світлого фону; `light` — для темного.

## Прозорість

Усі 12 PNG містять реальні прозорі пікселі. Чорний або білий демонстраційний
фон не є частиною файлу. Автоматичний тест:

1. звіряє SHA-256 кожного файла з corrected-набором;
2. читає PNG chunks та IDAT;
3. відновлює відфільтровані рядки PNG;
4. перевіряє, що мінімальне alpha дорівнює `0`, а сам знак не порожній.

Це захищає від повторення ситуації, коли preview на чорному тлі випадково
зберігається як непрозорий PNG.

## Використання в коді

- `app/site-config.ts` є єдиним джерелом шляхів до активного логотипа;
- `BrandLogo` вибирає світлий або темний файл;
- темна шапка/футер використовують `full-light`;
- favicon використовує `emblem-dark` на прозорому фоні;
- Open Graph використовує окремий `public/og-kaminchyk.jpg` із K-логотипом;
- не обрізати й не перемальовувати PNG у CSS, не змінювати пропорції;
- бронзовий акцент не перефарбовувати окремо без нового бренд-рішення.

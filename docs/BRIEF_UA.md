# Короткий робочий контекст Kaminchyk

Оновлено: 2 вересня 2026 року.

## Як стартувати малу задачу

1. Прочитати `AGENTS.md` і цей файл.
2. Відкрити лише ті файли, яких стосується задача.
3. `docs/HANDOFF_UA.md`, `docs/DECISIONS_UA.md` і весь `docs/` читати тільки
   для великих, ризикових або архітектурних змін.
4. Для UI спершу запускати локальний preview. `npm run dev` використовувати
   для hot reload; для ощадного перегляду готового static export запускати
   `npm run build`, потім `npm run preview:static`. Sites публікувати як
   релізний/demo-крок після перевірок, а не для кожної дрібної ітерації.

## Поточна база

- GitHub: `havrcode/kamin-korostyshiv`.
- Актуальна підтягнута база перед цією задачею: `v1.1.3`
  (`839315a`, `Release v1.1.3 Viber contact and catalog visibility`).
- Локальний кандидат після поточної роботи: `1.1.4`.
- Стек: React + TypeScript + Next.js App Router.
- Публічний frontend збирається як static export у `out/`.
- Vinext/Vite не повертати.
- Worker призначений тільки для `/api/*`, D1, Telegram, Access admin і
  приватної серверної логіки.

## Каталог зараз

- Пам’ятникові категорії збережені в даних, але приховані через
  `published: false`.
- Публічно показуються 5 категорій:
  `Столи та лавки`, `Лампадки`, `Вази`, `Інший декор`, `Камінь для дому`.
- Публічно показуються 38 товарів:
  14 столів/лавок, 7 лампадок, 6 ваз, 2 точені декори, 9 виробів для дому.
- Усі позиції мають режим ціни `Вартість уточнюється`.
- Зображення з позначкою `Візуалізація` не є фотографіями виконаних робіт.
- Для столів/лавок, лампадок, ваз, точеного декору й каменю для дому вже є
  окремі категорійні WebP-візуалізації; фото конкурента не копіювати 1-в-1.
- Головний екран знову використовує `hero-memorial.webp`; предметний комплект
  столу/лавки не ставити hero-фото, бо він може виглядати як неіснуючий
  дорогий товар.
- У простих столах і лавках зі стандартними опорами тримати вузькі квадратні
  ніжки. Не замінювати їх широкими монолітними або декоративними опорами без
  прямого погодження.
- Категорія `Столи та лавки` вже має 14 окремих товарних WebP-візуалізацій у
  `public/products/table-benches/`.
- Категорія `Лампадки` вже має 7 окремих товарних WebP-візуалізацій у
  `public/products/lamps/`.
- Категорія `Вази` вже має 6 окремих товарних WebP-візуалізацій у
  `public/products/vases/`.
- Категорія `Інший декор` вже має 2 окремі товарні WebP-візуалізації у
  `public/products/decor/`.
- Категорія `Камінь для дому` вже має 9 окремих товарних WebP-візуалізацій у
  `public/products/home/`.

## Найближчий крок

Після локальної перевірки desktop/mobile погодити, чи треба ще додавати
позиції в `Камінь для дому`. Сходи поки не відкривати публічно без окремого
рішення щодо замірів і відповідальності. Поточний ощадний варіант використовує
власні demo-візуалізації та не копіює фото конкурентів.
